# Formato de respuestas regulatorias

Las respuestas deberán distinguir:

## Evidencia

Información recuperada directamente desde una guía FDA PSG.

## Interpretación

Análisis técnico realizado a partir de la evidencia.

## Limitaciones

Información no disponible, resultados incompletos o aspectos que
requieren verificación adicional.

Toda guía utilizada debe identificarse mediante sus metadatos y su URL
FDA cuando estén disponibles.
