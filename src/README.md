# Directorio de Scripts (src)

Esta carpeta contiene los scripts y módulos de código del proyecto para el Agente de búsqueda de Product-Specific Guidances (PSG).

## Estructura sugerida

- `src/`: Código fuente principal del proyecto.
  - `src/scrapers/`: Scripts encargados de realizar scraping u obtención de datos (ej. descarga de CSVs/PDFs).
  - `src/processors/`: Procesamiento y análisis de datos.
  - `src/utils/`: Funciones auxiliares y herramientas comunes.
